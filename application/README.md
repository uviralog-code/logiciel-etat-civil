# Application — Logiciel d'état civil (Uvira)

Interface web du logiciel (Next.js 16, Tailwind CSS 4), reliée à la base Supabase du dossier `../supabase`.

```bash
npm install
npm run dev        # lancer en développement (http://localhost:3000)
npm run verifier   # types + règles de code + tests + compilation de production
```
